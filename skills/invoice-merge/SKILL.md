# 发票合并

## Overview

用本 skill 自带的合并工具，把一堆发票与单据 PDF 合成一份 A4 成品：自动分类排序、
小票拼版、带裁切虚线、整页转扫描件。**默认不打印**，除非用户明确说要。
macOS / Linux / Windows 三端通用。

流程只有三步：**定位脚本 → 直接合并 → 把成品展示给用户**。
不做合并前的分类核对，也不做合并后的版式检查——工具默认参数就是报销成品，直接跑。

## 第一步：定位可执行入口并选定解释器

整个 skill 目录自包含 —— 透传包装 `run.py` 和工具本体 `invoice_merge.py`
都在 `scripts/` 里，拷到任何机器都能跑。

**运行必须显式带上 Python 路径，用哪个解释器由你（agent）指定**：包装不做任何
解释器探测，拉起它的那个 Python 就是干活的 Python，所以请选一个已装 PyMuPDF 的：

```bash
# macOS / Linux
MERGE="<本 skill 目录>/scripts/run.py"
PY="<你选定的 python 路径>"        # 必须已装 PyMuPDF
```

```powershell
# Windows PowerShell
$MERGE = "<本 skill 目录>\scripts\run.py"
$PY = "<你选定的 python 路径>"     # 必须已装 PyMuPDF
```

后文一律写 `"$PY" "$MERGE"`（PowerShell 是 `& $PY $MERGE`）。不做版本预检——
解释器没装 PyMuPDF 时合并命令会以退出码 2 报「缺少依赖 PyMuPDF」，装上依赖重跑即可：
`"$PY" -m pip install -r "<本 skill 目录>/scripts/requirements.txt"`。

**不要**不带参数跑 —— 那会打开图形界面并阻塞，包装对此会直接拒绝（退出码 2）。

## 第二步：直接合并

用户给文件夹就用 `--folder`，给若干文件就用 `--files`，**默认参数直接跑，不要加
--dry-run，也不要自行"优化"**：

```bash
"$PY" "$MERGE" --folder "<输入目录>"
```

输出位置：

1. 用户指定了路径 → 用 `-o` 照办。
2. 用户没指定 → 不传 `-o`，让它落在输入文件夹里（文件名形如
   `发票合并_20260928_154312.pdf`）。这是安全的：工具列 PDF 时会跳过自己以前的产物。
3. 输入是零散文件、或输入目录明显不可写 → 用 `-o` 指到桌面或会话产物目录，
   并告诉用户为什么换了地方。
   **注意：`-o` 必须传完整的输出文件路径（以 `.pdf` 结尾），不能只传目录** ——
   传目录会被当成文件名，产出一个无后缀文件。想落进某个目录就用
   `-o "<目录>/发票合并_<时间戳>.pdf"` 的写法。

只在用户明确要求时才加参数：

| 用户说 | 加什么 |
| --- | --- |
| 要能选中文字 / 要原件 / 别压成图片 | `--no-scan` |
| 图太大 | `--scan-dpi 150` |
| 别给我拼版，一张一页 | `--no-band-merge` |
| 保持原始尺寸别缩放 | `--size keep`（注意这会同时关掉拼版） |
| 按拼音排 / 按时间排 | `--sort pinyin` / `--sort mtime` |
| 子目录里也有票 | `--recursive` |
| 我要打印 | 先确认打印机与份数，再加 `--print`（见下） |

## 第三步：把成品展示给用户

1. **抓输出路径** —— stdout 里 `输出：` 那一行就是成品；把文件展示出来
   （会话环境用文件展示卡片交给用户；桌面环境 macOS `open -R "<路径>"`、
   Windows `explorer /select,"<路径>"` 定位）。
2. **报结果** —— 顺带念出 `页数：`、`大小：`、`报告：` 三行。
3. **只盯异常** —— 出现 `跳过 N 项` 或退出码非 0 时，把原因告诉用户，
   别把残缺结果当成功；正常完成就不再做任何额外检查。

## 打印（默认不做）

打印会把纸送进物理打印机，属于外发动作。**先复述目标打印机与份数并拿到确认**，再执行：

```bash
"$PY" "$MERGE" --list-printers      # 先看有哪些、哪台是默认
"$PY" "$MERGE" --folder "<目录>" --print --printer "<名称>" --copies 1
```

macOS / Linux 走 CUPS（lp），可静默出纸。Windows 走系统"打印"动词、由 PDF 关联程序接手，
属"打开即打印"语义：`--copies` 可能不生效，个别阅读器（如 Edge）没注册打印动词时会
报失败，此时提示用户打开文件手动打印。

## 常见状况

- **"这张怎么这么小"** —— 打开 `xxx_报告.txt`，在 `提示与警告` 里找
  `内容放不下 1/N 页，已缩小到约 M%`。内容没被裁掉，只是缩放了。
- **合并结果比预期页数多** —— 多半是某个文件被归到了「其他材料」但只有一张，
  于是独占一页（不足三张不硬凑）。
- **扫描件选不中文字** —— 这是默认行为的预期结果。要文字层就加 `--no-scan`。
- **用户抱怨顺序乱** —— 类别顺序是 酒店发票 → 差旅费报销单 → 火车 / 飞机 → 其他 → 封面，
  同类内保持传入顺序。要手工调序，让用户在图形界面里拖，或先重命名再合并。
- **用户质疑某张归错类** —— 分类规则见 `references/rules.md`；改完文件名重跑即可。
